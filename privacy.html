Privacy policy for RCLN

RCLN is used with rclone, running on the user's own computers, to access Google Drive.

Access: With the user's consent, it can view, create, edit and delete files and file metadata in Google Drive.

Use: The data is used only to carry out the file operations the user starts.

Storage: Access tokens are stored in the rclone configuration on the user's own devices. Files are stored only where the user chooses to copy them.

Sharing: The developer runs no server, collects no data, and does not sell or share Google user data.

Limited Use: Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: Access can be removed at any time at myaccount.google.com/permissions.
